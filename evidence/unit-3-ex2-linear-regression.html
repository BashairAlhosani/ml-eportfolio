import matplotlib.pyplot as plt
from scipy import stats

#Create the arrays that represent the values of the x and y axis

y = [99,86,87,88,111,86,103,87,94,78,77,85,86]

#Execute a method that returns some important key values of Linear Regression
slope, intercept, r, p, std_err = stats.linregress(x, y)

# measure the correlation 
corr, _ = stats.pearsonr(x, y)
print('Pearsons correlation: %.3f' % corr)

#This new value represents where on the y-axis the corresponding x value will be placed

  return slope * x + intercept

#Run each value of the x array through the function. This will result in a new array with new values for the y-axis
mymodel = list(map(myfunc, x))

Experiments: how do changes in the data points affect the regression line?¶

The data is the W3Schools example: x = age of a car (years), y = its speed. Each experiment changes the data once and records the slope, intercept, Pearson's r, R², p-value and the predicted speed of a 10-year-old car.

import numpy as np
import pandas as pd
from scipy import stats

FIG = "3.Unit03 Ex2 - {}.png"
x0 = [5,7,8,7,2,17,2,9,4,11,12,9,6]
y0 = [99,86,87,88,111,86,103,87,94,78,77,85,86]

def fit(x, y, label, predict_at=10):
    res = stats.linregress(x, y)
    return {"experiment": label, "n": len(x), "slope": res.slope, "intercept": res.intercept,
            "r": res.rvalue, "R²": res.rvalue ** 2, "p_value": res.pvalue,
            "predicted y at age 10": res.intercept + res.slope * predict_at}

rng = np.random.default_rng(7)
experiments = {
    "1. original": (x0, y0, 10),
    "2. remove the old fast car (17, 86)": ([v for v in x0 if v != 17], [w for v, w in zip(x0, y0) if v != 17], 10),
    "3. move it to (17, 60)": ([*x0[:5], 17, *x0[6:]], [*y0[:5], 60, *y0[6:]], 10),
    "4. add an outlier (3, 60)": (x0 + [3], y0 + [60], 10),
    "5. every speed + 10": (x0, [v + 10 for v in y0], 10),
    "6. age in months (x * 12)": ([v * 12 for v in x0], y0, 120),
    "7. every point duplicated": (x0 * 2, y0 * 2, 10),
    "8. random speeds (no relation)": (x0, list(rng.integers(75, 112, len(x0))), 10),
}
results = pd.DataFrame([fit(x, y, k, p) for k, (x, y, p) in experiments.items()]).set_index("experiment")
results.round(4)

Leverage: which single point matters most?¶

Each point is removed one at a time, and the change in the slope is measured.

base = stats.linregress(x0, y0).slope
rows = []
for i in range(len(x0)):
    xs = x0[:i] + x0[i + 1:]
    ys = y0[:i] + y0[i + 1:]
    rows.append({"removed point": f"({x0[i]}, {y0[i]})", "new slope": stats.linregress(xs, ys).slope,
                 "change in slope": stats.linregress(xs, ys).slope - base})
pd.DataFrame(rows).sort_values("change in slope", key=abs, ascending=False).round(3).head(5)

Findings – simple linear regression¶

The original model is speed = 103.1 − 1.75 × age (r = −0.76, R² = 0.58, p = 0.003). It predicts 85.6 for a 10-year-old car: each extra year of age reduces speed by about 1.75.

Key lessons

  1. One high-leverage point controls the line. The 17-year-old car sits far from the other x values. Removing it changes the slope by −1.13, which is almost three times more than removing any other point. Points at the edges of the x-range have the most leverage.
  2. A single outlier can make a real relationship look non-significant. Adding the point (3, 60) dropped R² from 0.58 to 0.13, and the p-value rose above 0.05.
  3. Shifting or rescaling changes the coefficients, not the relationship. Adding 10 to every speed moves only the intercept. Measuring age in months divides the slope by 12. In both cases r, R² and the prediction (in the same units) are unchanged.
  4. More data is not always more information. Duplicating every point left the line unchanged but made the p-value about 370 times smaller (0.0026 → 0.000007). Repeated or non-independent records make results look more certain than they are, which is a data-quality and integrity issue.
  5. Regression always draws a line, even through random data. R² and p must be checked before trusting a prediction.
