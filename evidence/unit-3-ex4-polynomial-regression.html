It is important to know how well the relationship between the values of the x- and y-axis is, if there are no relationship the polynomial regression can not be used to predict anything.

The relationship is measured with a value called the r-squared.

The r-squared value ranges from 0 to 1, where 0 means no relationship, and 1 means 100% related

Experiments: polynomial regression¶

x = hour of the day that a car passes the tollbooth, y = its speed. The original model is a degree-3 polynomial.

numpy.polynomial.Polynomial.fit is used below. It gives the same curve as numpy.polyfit, but is numerically more stable at high degrees.

In [4]:
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from numpy.polynomial import Polynomial
from sklearn.metrics import r2_score

FIG = "3.Unit03 Ex4 - {}.png"
x0 = np.array([1,2,3,5,6,7,8,9,10,12,13,14,15,16,18,19,21,22])
y0 = np.array([100,90,80,60,60,55,60,65,70,70,75,76,78,79,90,99,99,100])

def loocv_rmse(x, y, deg):
    """Leave-one-out: fit without each point, then predict it. Measures performance on unseen data."""
    errs = [y[i] - Polynomial.fit(np.delete(x, i), np.delete(y, i), deg)(x[i]) for i in range(len(x))]
    return float(np.sqrt(np.mean(np.square(errs))))

Findings – polynomial regression¶

The original degree-3 model fits the tollbooth data well (R² = 0.943) and predicts a speed of 88.9 at 17:00.

Experiment 1 – degree of the polynomial

Degree R² (training) Error on unseen points (LOOCV RMSE) Prediction at 24:00
1 (straight line) 0.18 15.8 90.9
2 0.76 9.4 126.3
3 0.94 4.2 (lowest) 95.5
6 0.98 6.4 32.9
10 0.99 25.0 483.7
  • A straight line can't follow the U-shaped pattern (slow in the middle of the day), so R² = 0.18. Linear regression is the wrong tool here.
  • Training R² rises with every extra degree, but the error on unseen points is lowest at degree 3. Higher degrees start fitting the noise in individual points (overfitting). A degree-10 model has R² = 0.99 but predicts a car speed of 484 at midnight.
  • R² on the data used to fit the model isn't enough to choose a model. It has to be checked on data the model hasn't seen.

Experiment 2 – changing the data points

What I changed R² Pred. at 17:00 Pred. at 21:00
Original 0.94 88.9 99.1
Remove all points from 17:00 onwards 0.96 75.5 38.0
Add one slow car at 17:00 (40) 0.58 81.2 96.2
Add random noise to speeds 0.81 89.0 98.2
Random speeds (no pattern) 0.22 85.3 75.6
  • Missing data in a region gives confident but wrong predictions. Without the evening data, R² actually improved (0.96), but the model predicted 38 at 21:00, when the real speed is about 99. A high R² says nothing about regions the data doesn't cover.
  • One outlier dropped R² from 0.94 to 0.58 and pulled the 17:00 prediction down by 8.
  • With no real pattern, the curve still fits something (R² = 0.22). R² is the warning sign.

Overall reflection for Unit 3. In all four programmes, small changes to a few data points (one outlier, one high-leverage point, one missing region, one duplicated record) changed the conclusions much more than I expected. A coefficient, r or R² is only as trustworthy as the data behind it. Plotting the data, checking how widely it is spread, testing on unseen data, and not extrapolating beyond the observed range are essential before using correlation or regression to make real-world predictions.
