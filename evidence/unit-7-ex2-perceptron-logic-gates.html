def train():
    #
    total_error_value = 1
    # While the total_error_value is not equal to zero. we are asumming that at the start of running our network there will be no zero
    while (total_error_value != 0):
        #making the total_error 0 so we can do other calculations
        total_error_value = 0
        #Looping into each row of the dataset (remember indexing in python starts at zero hence 0-3 which are 4 values)
        for i in range(len(outputs)):
            #Calculating predictions
            prediction = cal_output(inputs[i])
            # Calculating the absolute value of the error
            error = abs(outputs[i] - prediction)
            #Updating the error
            total_error_value  += error
            
            if error > 0:
                for j in range(len(weights)):
                    #updating the weights for x1 and x2
                    weights[j] = weights[j] + (learning_rate * inputs[i][j] * error)
                    print('Weight updated to: ' + str(weights[j]))
        print('Total error Value: ' + str(total_error_value))

Experiments: other logic gates, a different update rule, and the learning rate¶

The training loop above has two special features:

  1. It uses the absolute error, abs(output - prediction). The weights can therefore only ever increase, even when the prediction is too high.
  2. There is no bias. The threshold is fixed at 1, so the input [0, 0] always gives a sum of 0 and an output of 0.

Its while loop also runs until the error is zero, so a gate it cannot learn would make it run forever. The function below repeats the same training but stops after a maximum number of epochs. It can also use the standard perceptron rule (Rosenblatt, 1958): a signed error (output - prediction) and a bias, which is a weight on an extra input that is always 1.

import pandas as pd
import matplotlib.pyplot as plt
from matplotlib.colors import ListedColormap

GATES = {"AND": [0, 0, 0, 1], "OR": [0, 1, 1, 1], "NAND": [1, 1, 1, 0], "XOR": [0, 1, 1, 0]}

def train_gate(targets, rule="original", lr=0.1, max_epochs=100):
    X = inputs if rule == "original" else np.c_[np.ones(len(inputs)), inputs]   # bias = constant input of 1
    w = np.zeros(X.shape[1])
    errors_per_epoch = []
    for epoch in range(1, max_epochs + 1):
        total = 0
        for i in range(len(targets)):
            prediction = step_function(X[i].dot(w))
            mistake = abs(targets[i] - prediction)
            total += mistake
            update = mistake if rule == "original" else targets[i] - prediction
            if update != 0:
                w = w + lr * update * X[i]
        errors_per_epoch.append(total)
        if total == 0:
            return {"learned": True, "epochs": epoch, "weights": w, "errors": errors_per_epoch}
    return {"learned": False, "epochs": max_epochs, "weights": w, "errors": errors_per_epoch}

results = {(rule, g): train_gate(t, rule) for rule in ["original", "standard"] for g, t in GATES.items()}
pd.DataFrame([{"rule": rule, "gate": g, "learned?": "yes" if r["learned"] else "NO",
               "epochs": r["epochs"] if r["learned"] else "stopped at 100",
               "final weights": np.round(r["weights"], 2).tolist(),
               "mistakes in last epoch": r["errors"][-1]} for (rule, g), r in results.items()])

Findings – training a perceptron (logic gates)¶

The original notebook learns the AND gate in 6 epochs, ending with weights [0.5, 0.5]. Only [1, 1] reaches the threshold of 1 (0.5 + 0.5).

Gate Original rule (absolute error, no bias) Standard rule (signed error + bias)
AND learned in 6 epochs learned in 5 epochs
OR learned in 10 epochs learned in 4 epochs
NAND never – the weights grow without limit (10.4 after 100 epochs) learned in 13 epochs (weights −0.2 and −0.2, bias 1.3)
XOR never never – still 4 mistakes every epoch

Why the original rule fails on NAND. NAND needs the output 1 for [0, 0], but without a bias the sum for [0, 0] is always 0, so that is impossible. NAND also needs negative weights, but abs(error) can only ever increase the weights. The notebook's while loop would therefore never stop. The standard rule (Rosenblatt, 1958) fixes both problems: the signed error moves weights down as well as up, and the bias shifts the line away from the origin.

Why no perceptron can learn XOR. XOR's 1s, at [0, 1] and [1, 0], sit on diagonally opposite corners from its 0s. No single straight line can separate them, so the problem is not linearly separable. Minsky & Papert (1969) showed this limitation formally. The perceptron learning rule is only guaranteed to converge when such a line exists. That is the motivation for the multi-layer network in the next notebook.

A larger learning rate learns faster, up to a point. At 1.0, the first update pushes both weights straight to 1, so [0, 1] and [1, 0] also reach the threshold and fire wrongly. The absolute-error rule then raises the weights again instead of lowering them, and they run away.

Lessons: an update rule must be able to move weights in both directions; a bias is needed in practice; and every training loop needs a maximum number of epochs, because real data is rarely learned to zero error.
