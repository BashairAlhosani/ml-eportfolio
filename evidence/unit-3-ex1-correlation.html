# calculate the Pearson's correlation between two variables
from numpy import mean
from numpy import std
from numpy import cov
from numpy.random import randn
from numpy.random import seed
from matplotlib import pyplot as plt
import seaborn as sns

from scipy.stats import pearsonr
# seed random number generator
seed(1)

# prepare data
data1 = 20 * randn(1000) + 100
data2 = data1 + (10 * randn(1000) + 50)

# calculate covariance matrix
covariance = cov(data1, data2)

# calculate Pearson's correlation
corr, _ = pearsonr(data1, data2)

# plot
plt.scatter(data1, data2)
plt.show()

# summarize
print('data1: mean=%.3f stdv=%.3f' % (mean(data1), std(data1)))
print('data2: mean=%.3f stdv=%.3f' % (mean(data2), std(data2)))
print('Covariance: %.3f' % covariance[0][1])
print('Pearsons correlation: %.3f' % corr)

Experiments: how do changes in the data points affect covariance and correlation?¶

Each experiment changes one thing in the data and records the covariance and Pearson's r. The original data is data2 = data1 + noise, where the noise has a standard deviation of 10.

import numpy as np
import pandas as pd
from numpy.random import randn, seed
from scipy.stats import pearsonr, spearmanr

FIG = "3.Unit03 Ex1 - {}.png"

def summarise(a, b, label):
    r, p = pearsonr(a, b)
    return {"experiment": label, "n": len(a), "covariance": np.cov(a, b)[0, 1],
            "pearson_r": r, "p_value": p}

def make_data(noise_sd, n=1000, s=1):
    seed(s)
    d1 = 20 * randn(n) + 100
    d2 = d1 + (noise_sd * randn(n) + 50)
    return d1, d2

Experiment 1 – Increase the noise (weaken the relationship)¶

The noise standard deviation in data2 is changed from 0 (a perfect line) to 80.

Experiment 4 – A non-linear relationship¶

Here data2 depends completely on data1, but through a U-shaped curve: data2 = (data1 - 100)².

In [6]:
seed(1)
d1 = 20 * randn(1000) + 100
d2_u = (d1 - 100) ** 2 + 20 * randn(1000)
res = summarise(d1, d2_u, "U-shape: (data1 - 100)^2")
res["spearman_rho"] = spearmanr(d1, d2_u)[0]

d2_exp = np.exp(d1 / 20)
res2 = summarise(d1, d2_exp, "monotonic curve: exp(data1 / 20)")
res2["spearman_rho"] = spearmanr(d1, d2_exp)[0]

Experiment 6 – Change the sample size¶

The same underlying relationship (noise sd = 40, true r ≈ 0.45) is sampled 1000 times at different sample sizes. How much does the measured r vary from sample to sample?

In [8]:
rng = np.random.default_rng(0)
rows = []
for n in [5, 10, 30, 100, 1000]:
    rs = []
    for _ in range(1000):
        x = 20 * rng.standard_normal(n) + 100
        y = x + 40 * rng.standard_normal(n) + 50
        rs.append(pearsonr(x, y)[0])
    rs = np.array(rs)
    rows.append({"n": n, "mean r": rs.mean(), "5th percentile": np.percentile(rs, 5),
                 "95th percentile": np.percentile(rs, 95), "% of samples with r < 0": (rs < 0).mean() * 100})
pd.DataFrame(rows).round(3)

Key lessons

  1. Covariance shows direction, not strength. Its size depends on the units and spread of the data, so it can't be compared across datasets. In Experiment 1 covariance rose slightly while the relationship got much weaker. Pearson's r is covariance divided by both standard deviations, so it is unit-free and bounded between −1 and 1.
  2. Pearson's r only measures linear relationships. A value near 0 does not mean the variables are independent. Always plot the data first.
  3. r is sensitive to outliers and to small samples. With n = 5, about 1 in 5 samples showed a negative correlation even though the true relationship was positive.
  4. In Unit 3 terms, correlation tells us how strongly two variables move together. It does not tell us why. Correlation is not causation.
