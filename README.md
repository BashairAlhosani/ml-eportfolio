# Machine Learning E-Portfolio

E-portfolio for the University of Essex Online Machine Learning module (July 2026), by Bashair Alhosani.

## Pages

| Page | File | Contents |
|------|------|----------|
| Home | `index.html` | Introduction and links to each section |
| Learning Artefacts | `artefacts.html` | Evidence for Units 1–12: readings, activities, wiki posts and discussions |
| Projects | `projects.html` | Unit 6 team project and Unit 11 individual project |
| Critical Reflection | `reflection.html` | Final reflection, unit reflections and references |

## Folders

- `evidence/` – screenshots and files linked from the pages. Use lowercase names with hyphens and no spaces, for example `unit-1-wiki-post.png`.
- `images/` – the Home page tile backgrounds.
- `assets/` – template styles, scripts and fonts. `assets/css/portfolio.css` holds the styles for the unit cards.

Sections that still need content are marked "To be added" on the pages.
