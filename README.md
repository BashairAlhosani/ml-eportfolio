# Machine Learning E-Portfolio

E-portfolio for the University of Essex Online Machine Learning module (July 2026), by Bashair Alhosani.

Live site: https://bashairalhosani.github.io/ml-eportfolio/

## Pages

The pages are read in this order; each ends with Previous / Next links.

| Page | File | Contents | Assessment criteria |
|------|------|----------|---------------------|
| Home | `index.html` | Introduction and links to each section | Structure and presentation |
| Learning Artefacts | `artefacts.html` | At least one artefact per unit (Units 1–12), each mapped to the learning outcomes | Application of knowledge, collaboration |
| Team Project | `team-project.html` | Unit 6 team project, my contribution and team meeting notes | Application of knowledge, collaboration |
| Individual Project | `individual-project.html` | Unit 11 project and its evaluation against the Unit 6 proposal | Application of knowledge, collaboration |
| Professional Development | `development.html` | Learning outcomes summary, peer and tutor feedback, skills matrix, PDP | Professional development requirements |
| Critical Reflection | `reflection.html` | Final reflection (max 1,000 words) using Rolfe et al.'s (2001) What? So what? Now what? | Criticality |
| References | `references.html` | All sources cited, in Harvard style | Academic integrity |

## Folders

- `evidence/` – screenshots and files linked from the pages. Use lowercase names with hyphens and no spaces, for example `unit-1-wiki-post.png`.
- `images/` – the Home page tile backgrounds.
- `assets/` – template styles, scripts and fonts. `assets/css/portfolio.css` holds the portfolio's own styles; `assets/js/portfolio.js` drives the unit bar on Learning Artefacts.

Sections that still need content are marked "To be added". Any section still without material once all 12 units are added will be removed, so the submitted portfolio has no empty sections.
